# Зертханалық жұмыс №7: Docker деген не? Контейнерлермен жұмыс 
**Пән:** DevOps үшін операциялық жүйелер
**Тақырыбы:** Docker негіздері және контейнеризация
---
## 1. Теориялық бөлім
### Виртуалды машина (VM) мен Контейнер (Docker) айырмашылығы:
* **Виртуалды машина:** Толық операциалық жүйені имтациялайды, ресурстарды көп қажет етеді және баяу жүктеледі.
* **Контейнер (Docker):** Хост ОС ядросын бөліседі, тек қосымшалар мен тәуелділіктерді оқшалайды. Женіл, жылдам  іске қосылады және ресурстарды үнемдейді.
--
## 2. Орындалған тапсырмалар
### Тапсырма 1. Docker орнату және негізгі командалар
Терминалда келесі командалар орындалады:
'''bash
docker --version            # Docker нұсқасын тексеру
docker pull hello-world     # Hello-world суретін жүктеу
docker run hello-world      # Контейнерді іске қосу
docker ps                   # Жұмыс іске тұрған контейнерді көру 
docker ps -a                # Барлық контейнерлер тізімін көру
docker images               # Жүктелген суреттер тізімі
docker stop <container_id>  # Контейнерді тоқтату
docker rm <container_id>    # Контейнерді өшіру
